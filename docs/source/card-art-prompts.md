# Starter card art (model-generated)

One standalone 1024×1536 PNG per card — no sprite sheets, no script rendering.
The starter set was drawn with an image model from the scene briefs below and
provided by the project owner as final PNGs (`raw pictures/`, kept out of git).
Rarity for each card is assigned in `src/main/resources/catalog/cards.json`.

## Calendar Cats special collection

Every card is a standalone 1024×1536 PNG using the established cozy kawaii
watercolor-gouache template and its normal rarity-colored frame. Every image
must also carry the same special marker: a small holographic eight-point star
medallion in the upper-right corner with a tiny calendar-page pictogram inside,
plus a thin rainbow-foil inner edge. The marker never replaces the top-left paw
badge and must remain visible at thumbnail size.

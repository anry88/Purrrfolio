# Новые постоянные коллекции — AND-12

Статус: все 88 изображений созданы через встроенный imagegen и добавлены в каталог.
Состав утверждён владельцем по AND-11 7 октября 2026: 24/24/20/20 карт.
Каждый PNG — самостоятельный native output 1024×1536 RGB, побайтово совпадающий
с runtime-копией. Число модельных попыток: 90.
Финальные тесты и production-проверка записываются после сборки релиза.

Все четыре темы — обычные и постоянные: без special-медальонов, foil,
сезонного/группового ограничения и premium-механики. Веса редкости прежние:
48/25/15/7/3/2 для C/U/R/E/M/L. За завершённую версию коллекции выдаётся один набор.
Новые карты входят в общий пул; шанс конкретной старой карты уменьшается.

Внутренний арт может опираться на Sleepy, Taxi Cab, March, Rooftop Kitty.
Рамка/плашка/буквенная форма берутся у существующей обычной карты нужной редкости;
March используется для внутреннего арта без календарного special-знака.
Точные использованные промпты, refs, native result paths, числа попыток и SHA-256
записываются в [new-collections-implementation.json](source/new-collections-implementation.json).
Утверждённый состав и соответствие исходным 44 идеям:
[new-collections-shortlist.json](source/new-collections-shortlist.json).

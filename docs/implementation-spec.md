# Purrrfolio — спецификация реализации (command-only MVP)

Документ основан на спецификации [`docs/source/cat_card_bot_game_design_v1_3.pdf`](source/cat_card_bot_game_design_v1_3.pdf) и адаптирован под **Telegram-бот без Mini App**.

## Продуктовая идея

**Purrrfolio / КотоКоллекция** — уютная коллекционная игра про кавайных котиков. Игрок собирает карточки, открывает наборы, завершает тематические коллекции и обменивает дубликаты через Random Trade и биржу.

**БЕЗ внутренней валюты**. Только Telegram Stars для покупки паков.

Целевая сессия: 1–3 минуты. Весь UX — команды, reply-клавиатура и inline-кнопки Telegram.

## Ключевые требования из PDF

- Минимум 1000 уникальных карточек в 10 коллекциях
- Каждая карточка — отдельный 1024×1536 PNG (не вырезка из сетки)
- 6 уровней редкости: Common → Uncommon → Rare → Epic → Mythic → Legendary
- Special — отдельный тег/статус (может сочетаться с любой редкостью)
- 3 стартовых пака по 3 карточки + 1 бесплатная карточка каждые 7 часов (первая — сразу)
- Random Trade механика через общий пул
- Биржа с предложениями своих выставленных карточек
- Telegram Stars для покупки паков (1 пак = 5 Stars, 3 пака = 12 Stars, 5 паков = 16 Stars, 10 паков = 25 Stars)

## Система редкостей

| Редкость | Цвет/эффект | Стартовый вес | Эмодзи |
| --- | --- | --- | --- |
| Common | кремовый / нейтральный | ≈ 48% | ⚪ |
| Uncommon | зеленый | ≈ 25% | 🟢 |
| Rare | голубой | ≈ 15% | 🔵 |
| Epic | фиолетовый | ≈ 7% | 🟣 |
| Mythic | малиновый / переливчатый | ≈ 3% | 🔴 |
| Legendary | золотой / особое сияние | ≈ 2% | 🟠 |

**Special** — НЕ является редкостью. Это отдельный тег/статус для event, limited, promo, achievement, gift, collaboration карточек. Может сочетаться с любой базовой редкостью.

## Стартовая механика

1. Новый игрок выбирает язык (RU/EN)
2. Получает 3 стартовых пака по 3 карточки
3. Первая бесплатная карточка доступна сразу, следующие — по одной каждые 7 часов от последнего клейма (`users.last_free_card_at`)
4. Бесплатные паки не накапливаются при наличии неоткрытых паков другого происхождения

## Telegram Stars pricing

| Покупка | Цена в Stars |
| --- | --- |
| 1 пак | 5 |
| 3 пака | 12 |
| 5 паков | 16 |
| 10 паков | 25 |

После оплаты паки добавляются в доступный запас, не открываются автоматически. Игрок получает кнопку «Открыть набор / Open Pack».

## Random Trade

- Лишний экземпляр уходит в общий пул
- Если есть карточка другого игрока с другим card_id — происходит обмен
- Одинаковые карточки друг на друга никогда не меняются
- Заявка ждет в пуле до нахождения пары

## Биржа

- Выставлять можно только дубли
- Игрок может смотреть свои листинги и возвращать карточки в коллекцию
- Просмотр чужих карточек по коллекциям/редкостям
- Предложение одной из своих выставленных карточек в обмен на чужой листинг
- Владелец принимает или отклоняет предложение

## Команды бота

```
/start          — регистрация, выбор языка, 3 стартовых пака
/collection     — список коллекций, пагинация по 10, галерея карточек
/pack           — открыть доступный пакет (стартовый, купленный или скрафченный)
/freecard        — забрать бесплатную карточку (первая сразу, далее каждые 7 часов)
/craft           — крафтер: плавить дубликаты в очки, 15 очков = 1 пак
/trade          — Random Trade (дубли в пул, обмен)
/market         — биржа (свои листинги, просмотр чужих, предложения)
/language       — сменить язык интерфейса (inline-кнопки EN/RU)
/help           — справка
/paysupport     — поддержка платежей и возвратов Stars
```

Reply-клавиатура: Коллекция, Набор, Обмен, Биржа, Купить наборы, Карточка, Крафт, Язык.

## Локализация

- При первом запуске выбор Русский или English
- Язык можно сменить командой `/language`
- Все сообщения, кнопки, описания команд, платежные тексты имеют RU/EN-версии
- Названия на изображениях остаются английскими
- Тексты должны звучать как игра: котейки, пушистики, лапки

## Модель данных

### Таблицы PostgreSQL

- `users` — telegram_user_id, language, last_free_card_at, craft_points, available_packs
- `collections` — id, code, localized_name, sort_order, active
- `cards` — id, collection_id, english_title, rarity_id, image_ref, sort_order, active, special/limited/event metadata
- `rarities` — id, code, probability/weight, frame_theme, sort_order
- `user_cards` — user_id, card_id, quantity
- `pack_ledger` — starter/stars начисления и opened-списания
- `random_trade_pool` — user_id, card_id, status, matched_trade_id
- `market_listings` — seller_id, card_id, status
- `trade_offers` — target_listing_id, offered_listing_id, status
- `payments` — Telegram payment IDs, Stars, packs granted, status
- `processed_telegram_updates` — идемпотентность webhook

## Потоки

### Регистрация

1. `/start` → выбор языка (inline-кнопки EN/RU)
2. Создать `users` row по `telegram_id` с выбранным языком
3. Добавить 3 стартовых пака в `pack_ledger` (source=starter)
4. Показать welcome + reply-меню + кнопку «Открыть набор»

### Открытие набора

1. Проверить `available_packs > 0`
2. Списать 1 пак из `pack_ledger`
3. Сгенерировать 3 карточки по весам редкости
4. Upsert `user_cards.quantity`
5. Отправить 3 сообщения с PNG и подписью редкости
6. Если карточка новая — пометка ✨ NEW

### Бесплатная карточка

1. Первая доступна сразу после регистрации (`last_free_card_at IS NULL`)
2. Клейм командой `/freecard` или кнопкой «🎁 Карточка», внутри — inline-кнопка «🎁 Забрать карточку»
3. Ролл 1 карточки по весам редкости, upsert `user_cards.quantity`
4. Обновить `last_free_card_at`; следующая — через 7 часов
5. Повторный тап перепроверяет таймер и карту не дублирует

### Крафтер паков

1. `/craft` показывает баланс очков (`craft_points` / 15) и дубликаты с ценой
2. Один тап сжигает 1 копию дубликата (одна всегда остаётся) и начисляет очки: Common = 1, Uncommon = 2, Rare = 3, Epic = 4, Legendary/Mythic = 5
3. Каждые 15 очков: счётчик сбрасывается, в `pack_ledger` добавляется 1 пак (source=craft)
4. Переполнение переносится: 14 + 2 = 16 → 1 пак + 1 очко в зачёт следующего
5. Скрафченные паки открываются через `/pack`

### Возврат карточек

- Случайный обмен: ожидающие заявки в `/trade` возвращаются кнопкой «↩️ Вернуть» (статус CANCELLED, копия назад в коллекцию)
- Биржа: свои лоты возвращаются кнопкой «↩️ Вернуть» в `/market` (статус CANCELLED, копия назад в коллекцию)

### Покупка паков за Stars

1. Интеграция с Telegram Payments API
2. После успешной оплаты — запись в `payments`
3. Добавить паки в `pack_ledger` (source=stars)
4. Показать подтверждение + кнопку «Открыть набор»

### Random Trade

1. Игрок выбирает дубликат для обмена
2. Карточка уходит в `random_trade_pool` со статусом WAITING
3. Система ищет пару: другой игрок с WAITING карточкой другого card_id
4. При нахождении — атомарный обмен, статус MATCHED
5. Уведомление обоим игрокам
6. Несостоявшуюся заявку можно вернуть кнопкой «↩️ Вернуть» (статус CANCELLED)

### Биржа

1. `/market list card_id` — создать `market_listings` (quantity−1 у игрока)
2. `/market browse` — просмотр активных листингов по коллекциям/редкостям
3. `/market offer listing_id my_listing_id` — предложить обмен
4. Создать `trade_offers` со статусом PENDING
5. Владелец принимает/отклоняет через inline-кнопки
6. При принятии — атомарный обмен карточек

## Геометрия карточек

- Финальный размер: 1024 × 1536 px (2:3)
- Формат: PNG, RGB/sRGB
- Safe area: 24 px от внешнего края
- Внешняя рамка: 24-32 px, скругление 55-65 px
- Основная арт-зона: примерно x=45-979; y=35-1250
- Nameplate: примерно y=1240-1480; высота около 240 px
- Paw badge: верхний левый угол, область около 175-190 px

## Definition of Done

- Не менее 1000 уникальных карточек минимум в 10 коллекциях
- Каждая карточка — самостоятельный 1024×1536 PNG, не вырезка из сетки
- Единый master-template рамки, плашки, badge и типографики
- Английское название занимает 1-2 строки, корректно переносится и автоматически масштабируется
- Редкость соответствует шкале Common → Uncommon → Rare → Epic → Mythic → Legendary
- Special хранится отдельно от редкости и может сочетаться с любым rarity
- Внутренний арт уникален и соответствует качеству эталона Sleepy
- Нет случайного текста, артефактов, пикселизации и обрезанных элементов
- collection_id и sort_order заполнены
- Файл прошел автоматическую проверку формата/разрешения и визуальный QA

## Нефункциональные требования

- Kotlin 17 + Spring Boot 3, PostgreSQL, Flyway
- Webhook с `X-Telegram-Bot-Api-Secret-Token`
- Идемпотентность по `update_id` через таблицу `processed_telegram_updates`
- Prometheus metrics на `:9090/actuator/prometheus`
- Docker Compose для локального PostgreSQL
- Telegram Payments API для Stars
